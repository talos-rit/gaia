# Agent Instructions

## Documentation

`README.md` is a human-written, guide-first document. It intentionally doesn't cover every change, so keep it that way.

- **Don't** add small features, options, or fixes to `README.md`.
- **Do** add major feature changes to [README_DETAILED.md](README_DETAILED.md) instead.
- Only edit `README.md` when something in it becomes factually untrue, or when a major expansion of functionality genuinely needs a guide-level mention.
- When you do edit `README.md`, keep the change minimal and in its existing voice and structure.

`CLAUDE.md` is a symlink to this file, so edit `AGENTS.md`.
